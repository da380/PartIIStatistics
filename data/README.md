# Data sets

Small data files used by the notebooks. All are read directly from GitHub by the notebooks, so nothing needs downloading.

| File | Contents | Source |
|---|---|---|
| `old_faithful.csv` | 272 eruptions of the Old Faithful geyser: eruption duration and waiting time to the next eruption (minutes) | Azzalini & Bowman (1990), *Applied Statistics* 39, 357–365, as distributed in R's `datasets` package |
| `mauna_loa_co2_monthly.csv` | Monthly mean atmospheric CO₂ at Mauna Loa Observatory, 1958 onwards (ppm), with a deseasonalised series | NOAA Global Monitoring Laboratory, https://gml.noaa.gov/ccgg/trends/ (public domain) |
| `gistemp_global_annual.csv` | Annual global mean surface temperature anomaly relative to 1951–1980 (°C), 1880 onwards | NASA GISS Surface Temperature Analysis (GISTEMP v4), https://data.giss.nasa.gov/gistemp/ (public domain) |
| `usgs_earthquakes_M5_2014_2023.csv` | All earthquakes of magnitude 5.0 and above, 2014–2023: origin time, latitude, longitude, depth (km), magnitude | USGS Earthquake Catalog, https://earthquake.usgs.gov/earthquakes/search/ (public domain) |
| `pearson_york.csv` | Ten-point test data set with uncertainties in both variables, used to test straight-line fitting with errors in $x$ and $y$ | Pearson (1901) with the weights of York (1966); see York et al. (2004), *Am. J. Phys.* 72, 367 |

The files were downloaded in September 2026 and trimmed to the columns used in the notebooks.
